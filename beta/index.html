Beta: Trader Joe's Microinteractions

Original Interface: Trader Joe's - From the Freezer

Triggers:

  • Object: “+ ADD TO LIST” button centered at the bottom of a product’s card
    • Click off
  • Object: Rectangular food item card that is repeated throughout page, below “Cool Desserts” text
    • Hover on
    • Hover off
    • Click
  • Object: Rectangular food item image at the top of item card
    • Hover on
    • Hover off
    • Click

Rules:

  • Object: “+ ADD TO LIST” button
    • Click off:
      • Button width shrinks back to default width
      • Check mark icon switches back to default plus icon
      • Text switches back to default “ADD TO LIST”
      • Border color fills with default brownish-red color
      • Button boarder weight shrinks back down (about 1px)
      • Item is removed from internal shopping list database (and interface on different page)
  • Object: Food item card
    • Hover on
      • Shadow effect appears beneath card, giving illusion that card is lifted
      • Mouse switches to pointer
    • Hover off
      • Shadow effect disappears from beneath card, defaulting it back to flat state
      • Mouse switches back to default arrow
    • Click
      • Shadow effect appears beneath card, giving illusion that card is lifted
      • Mouse switches to pointer
      • Clicking navigates to item description page
  • Object: Food item image
    • Hover on
      • Shadow effect appears beneath card, giving illusion that card is lifted
      • Mouse switches to pointer
      • Image animates and flips to nutrition label
    • Hover off
      • Shadow effect disappears from beneath card, defaulting it back to flat state
      • Mouse switches back to default arrow
      • Image animates and flips back to item image
    • Click
      • Shadow effect appears beneath card, giving illusion that card is lifted
      • Mouse switches to pointer
      • Clicking navigates to item description page

Feedback:

  • Object: “+ ADD TO LIST” button
    • Click:
      • Button width shrinks back to default width
