Final Build: Trader Joe's Microinteractions

Cool Desserts

Link copied!

Mango Cream Bars

$3.49/15 Fl Oz

Triggers:

  • Object: “+ ADD TO LIST” button centered at the bottom of a product’s card
    • Hover on
    • Hover off
    • Click on
    • Click off
  • Object: Rectangular food item card that is repeated throughout page, below “Cool Desserts” text
    • Hover on
    • Hover off
    • Click
  • Object: Rectangular food item image at the top of item card
    • Hover on
    • Hover off
    • Click
  • Object: Heart icon on right of item card, below image
    • Click on
    • Click off
  • Object: Copy link icon on right of item card, below image
    • Click

Rules:

  • Object: “+ ADD TO LIST” button
    • Hover on:
      • Cursor instantly changes to finger
      • Drop shadow grows (about 20% opacity over about .3 seconds)
      • Button border weight thickens (about 3px over about .3 seconds)
      • Button color fills with beige (over about .3 seconds)
    • Hover off:
      • Cursor instantly changes back to default arrow
      • Drop shadow shrinks back to default (over about .3 seconds)
      • Button border weight thins back to default (over about .3 seconds)
      • Button color fills back to default white (over about .3 seconds)
    • Click on:
      • Button gets wider (over about .3 seconds)
      • + icon switches to check mark
      • Text switches to "ADDED TO LIST"
      • Border color fills with red
      • Button border weight thickens (about 3px)
      • Item is added to internal shopping list database (and interface on different page)
    • Click off:
      • Button width shrinks back to default width (over about .3 seconds)
      • Check mark icon switches back to default plus icon
      • Text switches back to default “ADD TO LIST”
      • Border color fills with default brownish-red color
      • Button border weight shrinks back down (about 1px)
      • Item is removed from internal shopping list database (and interface on different page)
  • Object: Food item card
    • Hover on
      • Shadow effect appears beneath card, giving illusion that card is lifted (over about .3 seconds)
      • Mouse instantly switches to pointer
    • Hover off
      • Shadow effect disappears from beneath card, defaulting it back to flat state (over about .3 seconds)
      • Mouse instantly switches back to default arrow
    • Click
      • Shadow effect appears beneath card, giving illusion that card is lifted (over about .3 seconds)
      • Mouse instantly switches to pointer
      • Clicking navigates to item description page
  • Object: Food item image
    • Hover on
      • Shadow effect appears beneath card, giving illusion that card is lifted (over about .3 seconds)
      • Mouse instantly switches to pointer
      • Image animates and flips to nutrition label
    • Hover off
      • Shadow effect disappears from beneath card, defaulting it back to flat state (over about .3 seconds)
      • Mouse instantly switches back to default arrow
      • Image animates and flips back to item image
    • Click
      • Shadow effect appears beneath card, giving illusion that card is lifted (over about .3 seconds)
      • Mouse instantly switches to pointer
      • Clicking navigates to item description page
  • Object: Heart icon
    • Click on
      • Heart grows and shrinks
      • Heart fades in with red
      • Heart border fades to red
      • Item is added to internal favorites list database (and interface on different page)
    • Click off
      • Heart icon grows and shrinks
      • Heart's red fill fades out back to default
      • Heart's border fades back to default
      • Item is removed from internal favorites list database (and interface on different page)
  • Object: Copy link icon
    • Click
      • Copy link icon grows and shrinks
      • Text appears below the icon saying, "Link copied" for 1.5 seconds and then disappears
      • Item link is copied to clipboard
